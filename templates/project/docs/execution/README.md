# Execution state

status: none

Questo file è il puntatore operativo al lavoro attivo del repository corrente.

Usare `status: none` quando non esiste una wave attiva in questo repository. Quando esiste una wave attiva in questo repository, indicare qui il percorso o riferimento della wave. Wave attive in altri repository non modificano questo stato. Non dedurre il lavoro attivo da nome, data o ultima modifica.

Alla chiusura della wave, aggiornare questo file nella stessa modifica che registra la chiusura.
